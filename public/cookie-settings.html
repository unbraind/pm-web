This page describes package capabilities, not an operator's full deployment.

Package defaults

pm-web can use an HTTP-only pm_token session cookie, short-lived OIDC flow state when configured, and local browser preferences such as theme, PWA prompts, and this banner choice.

Operator verification required

Reverse proxies, identity providers, analytics, embeds, support tools, and other deployment components may add cookies or storage. Inventory the running service and replace this page with a reviewed disclosure.

No package-level consent claim

The reusable package cannot decide which storage is necessary, optional, or consent-based for an unknown deployment and jurisdiction.
