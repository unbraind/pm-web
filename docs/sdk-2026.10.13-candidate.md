# SDK 2026.10.13 candidate

The standalone host now exact-pins `@unbrained/pm-cli` 2026.10.13 in its
manifest and lockfile, replacing 2026.10.10. The separately certified minimum
extension-host version remains as declared in `manifest.json`.

Reviewed the upstream [10.11](https://github.com/unbraind/pm-cli/releases/tag/v2026.10.11),
[10.12](https://github.com/unbraind/pm-cli/releases/tag/v2026.10.12), and
[10.13](https://github.com/unbraind/pm-cli/releases/tag/v2026.10.13) notes.
Relevant fixes cover linked-test context validation, registered relationship
kinds, schema helper types, and MCP warning enforcement. Universal extension
read controls are opt-in. Existing host calls need no source adaptation.
This dependency-only change has no changed function requiring a behavioral
revert proof; runtime identity is independently checked in the built image.

## Local validation

Validation receipts are finalized in the accompanying PR. Gate thresholds are
unchanged. Build command: `docker build -t pm-web:sdk1013-candidate .`.

The candidate image `sha256:0106286199529d0c451c917126fc19e34326d63133ac011909bcc60c49b5b215`
booted with SDK 2026.10.13, `/healthz` 200 (database and projects healthy),
and `/` 200. The proof used a new internal Docker network, disposable
PostgreSQL 17, and tmpfs projects. No bind mounts, existing volumes, hosted
data, production credentials, or running services were used.
